# Высота — сайт ЖК с 3D-небоскрёбом, выбором этажа и ипотекой

Демо-проект для портфолио: ЖК, цены и планировки вымышленные, сайт рабочий.

**Открыть:** https://davnat0111-gif.github.io/vysota-residence/

## Что умеет
- **3D-башня на 40 этажей и ночной город (Three.js):** этаж выбирается кликом прямо по башне (raycasting) или ползунком, башню можно крутить мышкой
- **Подбор квартир:** фильтр по комнатам и цене подсвечивает подходящие этажи на 3D-башне
- Карточки квартир с планировкой (SVG), площадью, ценой за м² и статусом брони
- **Ипотечный калькулятор:** аннуитетный платёж, переплата, диаграмма; цена выбранной квартиры подставляется сама

HTML, CSS, JavaScript без фреймворков. Сделано с помощью Claude Code.
